// Module overview

Single-product deployments, multi-platform brand systems, and end-to-end UX audits are all the same module — different props. Research and synthesis are mandatory. Visual design is where the work gets judged, and handoff is where it lives or dies.

I work in the same tools as the team. Figma as the default. FigJam when we need a wall. Framer when something needs to be live. Webflow when it's a marketing site. Protopie when the interaction has to be felt. Miro when the room is distributed.

// Input

Asian Paints dealers were calling sales reps to place every order. Competitor portals existed; dealers hated all of them. Transaction volumes were flat, AOV was flat.

// Process

Heuristic evaluation, then end-to-end redesign across twelve screens (Home, Trending, Categories, Catalog, Listing, Order, Stock, Wishlist, Cart, Tracking, Account, Reports). Added barcode-scan ordering, personalized recommendations, loyalty points, and AOV incentives.

// Output

+20% in online transaction volume. Healthy increase in user engagement and loyalty. New features reduced dealer-salesman interaction and cut costs.

Mobile (iOS, Android)
Outcome
−60% uninstall rate

// Input

80% of new Boost360 users uninstalled the app before signing up. Average time-to-signup was 30 minutes. Something between the marketing and the product was breaking.

// Diagnosis

Not crashes, OTP, ads, or permissions. It was a mismatch between what marketing promised and what onboarding delivered — a UX problem hiding inside a positioning problem.

// Output

Visual signup, USPs communicated during onboarding, social proof for trust, quick wins to demonstrate value, and a route to support. Usability testing confirmed the new flow was understandable and motivating. −60% uninstall rate within 14 days.

// Input

Wikimedia wanted to understand JioPhone (KaiOS) users — people who chose a feature phone over a smartphone, and what that meant for Wikipedia on their device.

// Method

25 in-person interviews, 45–60 minutes each, across Pune, Mumbai, Delhi. Recruited, ran the sessions, transcribed, built personas, mapped journeys, and produced an ecosystem map and recommendations report.

// Output

Concrete recommendations: voice-first interaction, readability optimization for small screens, video content, search visibility, regional-language SEO, simpler Hindi. Findings shaped how Wikipedia approached KaiOS for the next year.
